Como gerar meu link ↗Primeiros passos ↗
O Mercado Livre não gera comissão em links para páginas genéricas como buscas, categorias, carrinho e página inicial. Gere sempre o link de um produto específico pela sua Central de Afiliados. A validação do formato do link não comprova que a atribuição de comissões está ativa.

🟡 Mercado Livre Afiliados

Importação por um link, cadastro manual ou lote, pontuação e seleção automática de produtos cadastrados. O sistema tenta identificar o anúncio pela URL e obter detalhes através da API oficial somente com credenciais autorizadas. Sem acesso à API, os dados não confirmados ficam pendentes.

● Importação oficial por link • Sem API pública de afiliados para gerar links

Central Mercado Livre ↗

Divulgue somente nos canais públicos permitidos e cadastrados na conta de afiliado. Não automatizamos a criação de links com sessões, cookies ou extensões não autorizadas.

Como os marketplaces trabalham juntos

Produtos das duas plataformas entram no mesmo catálogo, são pontuados pelas mesmas regras e podem gerar campanhas em simulação. A publicação real só será habilitada após conectar os canais de destino, verificar as permissões e seguir os termos de cada marketplace.
